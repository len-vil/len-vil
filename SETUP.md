# Install the Lenvil GitHub profile

1. Open https://github.com/len-vil/len-vil
2. Open `README.md` and click the pencil (Edit) button.
3. Replace its contents with the `README.md` from this package.
4. Commit the change to `main`.
5. Upload the `assets/` and `cards/` folders to the repository root, preserving their names.

The README expects these paths:
- `assets/top-banner.jpg`
- `cards/intro.svg`
- `cards/projects.svg`

The top banner is the exact image supplied in the conversation. The SVG cards use subtle SVG animation; GitHub's rendering/sanitization may affect animation support, while the layout and text remain readable without it.
